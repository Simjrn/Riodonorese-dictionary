# About Riodonorese spelling

Riodonorese doesn't have a standard spelling system, so this course will use the system used in the stories on duostories.org for consistency across resources, which is meant to be as similar as possible the spellings used in other neighbouring languages. However, some texts you find might write words slightly differently. Generally, most sound exactly the same when you sound them out phonetically.

# Vowels

### Basic vowel sounds

Riodonorese has five vowels : a, e, i, o, u. Relative to English, these are pronounced like 'ah', 'eh', 'ee', 'o', 'oo' respectively.

### Stress

Stress almost always falls on the last two syllables, usually the second to last. However, when you see an accent above a vowel, you know to stress that syllable instead.

### Differences compared to other writing systems

In other texts, you will also see triangular accents on top of vowels, in words like 'biên', however this resource, as well as some others, omits these accents since they are mostly unneeded.

Also, when the 'i' sound is used as a glide between other vowels, it is in this resource written as 'y'. For example, 'ie' -> 'ye'.

# Consonants

### Basic consonant sounds

Consonant sounds are mostly similar to English, so I'll run through the different ones here:

- H is silent
- R is a rolled r
- X is a 'sh' sound

### Other ways of writing

The 'ch' sound is written the same as english in this resource, however it is sometimes also written as 'tch' to be consistent with Portuguese.

Also, in adjectives ending in 'ado' and 'ada', they are spoken as 'áu' and 'áa'. Sometimes, you will see them written like that, however here they are written like with the 'd', because that is how they are written in Spanish, and the 'd' is often skipped in Spanish anyway.
